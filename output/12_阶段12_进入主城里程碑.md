## 本阶段定位到的三个根因

### 1. `NetworkManager::OnInitNetWork`（rva=0x241ac0）注册在 S→C msgid=1

`NetworkManager::Init`（0x2412e8）把三个处理器注册到 `NetMsgGlobalHandler`：

| msgid | 处理器 | 作用 |
|---|---|---|
| 1 | `OnInitNetWork` | 置 `IsInitWithSvr=1`，发事件 652；若重连标记则回发 601 |
| 2 | `OnRecvDisConnectMsgBySvr` | 服务端断开通知 → 事件 658 |
| 3 | `OnRecvHeartBeatMsgFromSvr` | 心跳应答 → 刷新心跳时间戳 |

### 2. 弹"网络异常/返回登陆"的真正触发链

`ConnectDetectSystem::Update`（0xa136c）逻辑：

```
if (careNet 且 NetState == 0):
    ConnectDetectUI.Open()          ← 加载界面上的"连接中"
    timer += unscaledDeltaTime
    if timer > MaxWaitDisconnectNetWork:  弹 100887/100888/100892/100889
```

- `NetState`（字段 rid 5134）**初始为 1**，只有事件 **656（连接关闭）/657（连接错误）** 会置 0；
- 656/657 由 `NetworkManager::OnClosed` / `OnError` 发出；
- 恢复手段是 `Reset()`，只由事件 **653/654（`OnReConnectRet`，即收到 901）** 触发。

### 3. 卡加载的死路：1301 把客户端带进建角分支

关键实测证据（`server/logs/game_server.log` 01:21:15 会话）：

- **发 1301（NotifyCreateRole）**：客户端切到建角 UI → 1001 → 1302 →
  `ShowEnterAni` → 事件 661 → `LoadScene(98)` → **永远停在加载界面**。
- **不发 1301**：客户端收到 101 Ret 后**直接**发 5401 → 5402 → 102 → 进主城。

因此：**已有角色时不发 1301**；只有存档为空时才走建角流程。

### 4. 附带修复：5301 空 body 会让客户端崩溃

Unity logcat（15:25:50 会话）：

```
ArgumentException: The thing you want to instantiate is null.
  at MobileGameDemo.SceneEffectManager.SetDaTingEffect (System.String effectName)
  at ᝁ.OnNofiyDaTingEffect (System.IO.MemoryStream inputStream)
  at NetMsgGlobalHandler.OnRecvMsg ...
```

5301 = `OnNofiyDaTingEffect`（大厅特效），空 body → effectName 为空 →
`Instantiate(null)` 抛异常，打断消息处理链。已默认关闭。
