# 05 — 配置表格式规范与字段结构（从 Client.dll IL 反汇编确定）

> 来源：`Client.dll`（CAB-Client 内 carve 出的 PE），用 dnfile + dncil 反汇编 `*CfgMgr..ctor` 与 `*Cfg..ctor` 得出。
> 结论：**配置表格式完全确定，可以程序化生成**。

## 一、格式规范（IL 级证据）

| 项 | 值 | 证据 |
|---|---|---|
| 行分隔符 | 空格(0x20) 与 Tab(0x09) **同时生效** | `newarr char[2]; [0]=32; [1]=9` |
| 空项处理 | `StringSplitOptions.RemoveEmptyEntries`（值 1） | `Split(sep, 1)` |
| **第 0 列** | **被忽略**（解析从 `tokens[1]` 开始） | `.ctor` 中 `ldloc.0` 初值 = 1 |
| 列顺序 | = 类字段在元数据中的**声明顺序** | 逐个 `stfld` 递增索引 |
| List 列 | 用竖线 `|`(124) 再分割 | `newarr char[1]; [0]=124` |
| 跳过行 | `tokens[0]` 满足某条件时跳过（注释/表头行） | Mgr..ctor 中 `ldstr; call; brfalse` 跳过 |
| 加载时机 | **`Mgr` 的构造函数**（`.ctor`），不是 `Init`（`Init` 是空方法） | 已反汇编确认 |
| 存储 | `Dictionary<ID, Cfg>` | `ldfld dict; ldfld cfg.ID; callvirt Add` |

## 二、加载流程（还原伪代码）

```csharp
class XxxMgr {
  XxxMgr() {                       // 配置在构造函数里加载
    var text = LoadText("GameData/Xxx.txt");
    var reader = new StringReader(text);
    while ((line = reader.ReadLine()) != null) {
      var t = line.Split(new[]{' ','\t'}, RemoveEmptyEntries);
      if (t.Length == 0) continue;
      if (t[0].StartsWith(COMMENT)) continue;   // 注释/表头
      var cfg = new XxxCfg(t);                 // 按列顺序赋值
      dict.Add(cfg.<ID>, cfg);
    }
  }
}
```
