# 01 — protobuf 消息清单（从 Msg.dll 静态提取）

- 程序集：**Msg**，命名空间 `NetProto`
- 消息类型：**421** 个，字段 **1413** 个
- 提取方式：dnfile 解析 CLI 元数据 + `[ProtoContract]` / `[ProtoMember(n)]` 特性
- 字段语法：`[编号] 类型 字段名`
