# 04 — 身份鉴定报告：果盘 8.1.0 包不是《梦幻神域》（我们手上的这款）

> 日期：2026-09-29
> 结论：**同名不同游戏**。用户对宣传图的怀疑是对的。
> 鉴定过程未下载完整包（远程 HTTP Range 抽查约 3.3 MB 数据）。

## 一、判定：不换包。撤回"用 guopan 8.1.0"方案

## 二、证据链

| 维度 | 我们的游戏（UC 4.0.0.2） | 果盘包（8.1.0） | 判定 |
|---|---|---|---|
| 包名 | `com.fl.mhsy.uc`（飞流） | `com.jiayou.mhsy.guopan`（悦浪/嘉游） | 不同发行商 |
| 图标 | Q 版黑发少年（桐人）+ 九游水印 | 红底金字"梦幻神域" | **美术完全不同** |
| 闪屏 | 橙色卡通 LOGO + 蓝剑城堡 | 仅"游戏健康忠告"黑屏 | 不同 |
| 引擎 | Unity 4.6.3f1（2015） | Unity 5.3.6p8（2016） | 重建 |
| 网络层 | SuperSocket TCP + protobuf-net | libkcp.so（KCP/UDP）+ uLua | 完全不同 |
| 核心库 | ClientCore.dll + Client.dll | YLCore.dll 2.8MB | 完全不同 |
| 版本线 | 4.0.0.2（官方最新 v4.4.1.1） | 8.1.0 | 两套版本体系 |
| 保护 | 无加固无混淆 | libxguardian.so 加固 + data.yfs 加密 + GameText.txt.bytes 加密 + 资源名混淆 | 不同产品 |

百度百科佐证：真正的《梦幻神域》= 2015-08-04 发行、改编自《刀剑神域》、Unity3D、
Q萌画风、**最新版本 v4.4.1.1**（133.6~151 MB）—— 与我们手上的 4.0.0.2 同一条版本线。

果盘包内置审核服 `123.59.116.254:8991`、更新服 `fnclientversion.yuelangnet.com`（已死）、
product 代号 `shbt` —— 均与悦浪产品线关联，与飞流九天无关。

## 三、对项目的影响

- 换用 guopan 包 = 换成另一个游戏，且协议/资源全加密带加固 → **难度更高还认错了对象**。放弃。
- 我们已导出的 421 个消息契约、登录链路、热更机制分析**继续有效**（基于正确的包）。
